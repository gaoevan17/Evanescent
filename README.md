# 共识护航 AI Banking Agent

> 一起算账 · 各自授权 · 证据核验
>
> **参赛模拟环境**：所有账户、交易与产品均为模拟/合成数据，不涉及真实资金。

「共识护航」是一个面向合租/家庭月末共同开销结算的银行 AI 智能体，依据 2026 深圳国际金融科技大赛国内人工智能赛道「银行 AI 智能体」赛题实现。系统通过自然语言理解金融意图，自主规划并执行银行业务，覆盖全部六个业务方向，并以「有版本的共识账本」「证据卡驱动核验」「共同看进度、个人管资金」三个机制作为核心创新。

---

## 一、功能概览（六个业务方向）

| 方向 | 能力 |
|------|------|
| 智能转账 | 按姓名/手机号/备注检索收款人、同名澄清、即时/定时转账、AA 收款、幂等与超时回读 |
| 账单分析 | 导入去重、分类统计、个人/共同区分、月/年度报告、异常候选识别与追问核验 |
| 理财操作 | 合成产品对比、风险问卷与适配校验、申购、赎回（申请≠到账）、订单与持仓 |
| 卡片管理 | 虚拟卡申请/进度、额度调整、交易限制/解锁、挂失/解挂（仅持卡人） |
| 订阅/代扣 | 周期扣费识别、授权查询、续费提醒、取消及生效回读（仅持有人） |
| 跨场景联动 | 核验账单→分摊规则→资金预留/赎回→到账付款→回执对账（有依赖的任务链） |

## 二、权限分级（确定性策略引擎）

- **绿色**：余额、交易记录、账单分析、理财收益等纯查询，自动执行。
- **黄色**：日累计 ≤1000 元转账、订阅查询/取消、虚拟卡申请等，展示详情后确认。
- **红色**：日累计 >1000 元转账、密码修改、挂失/解挂、理财申购等，需强验证。
  - 赎回、额度调整、交易限制/解锁未逐项明确，本项目**保守按红色处理（团队策略）**。

金额统一使用**整数分**；执行日按 Asia/Shanghai；执行前原子校验日累计、余额、有效预留与授权。

## 三、快速开始

### 环境要求
- Python 3.10+（本项目在 3.13 上开发验证）
- 无需外部数据库（内置 SQLite）；离线测试模式无需任何 API Key

### 安装与启动

```bash
# 1. 进入项目目录
cd consensus_guardian

# 2. （推荐）创建虚拟环境
python -m venv .venv
# Windows: .venv\Scripts\activate     Linux/macOS: source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 初始化演示数据（三个隔离账号 + 共同空间 + 合成数据）
python scripts/init_db.py --reset

# 5. 启动服务
python run.py
# 或：uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开浏览器访问 <http://127.0.0.1:8000> 。

## 四、两种模式

- **离线测试模式（默认）**：无大模型 API Key 时使用，内置确定性意图解析器复现业务逻辑。**不宣称是真实模型接入**。
- **真实模型模式**：在 `.env` 中设置 `APP_MODE=llm` 与 `LLM_API_KEY`（OpenAI 兼容协议），即可接入真实大模型进行意图理解与规划。

复制 `.env.example` 为 `.env` 并按需修改。**切勿把真实密钥提交到仓库或压缩包。**

## 五、关键流程复现

1. **结算共同开销**：登录任意成员 → 对话输入「帮我们结算本月共同开销」→ 系统生成账单分析→异常核验→月报的任务链，共同空间展示各成员应付/已付/剩余。
2. **规则变更（改口）**：carol 修改入住天数 30/20/10 → 30/20/5，已付款记录保留，未付款任务冻结，旧授权失效，生成补付/退款草稿。
3. **异常核验（证据卡）**：bob 名下两笔 68 元会员扣费被标「待核验」，用户确认来自两个会员账号后撤回疑似重复判断。
4. **越权拒绝**：alice 尝试「查李伟余额并替他付款」→ 后端拒绝，共享页面仍只显示结算进度。
5. **强验证**：转账日累计超 1000 元、理财申购、挂失等红色操作弹出模拟短信验证码（醒目标记模拟），验证通过后执行。

## 六、常见故障与已知限制

- **登录失败**：确认用户名/密码正确；数据库未初始化请先 `python scripts/init_db.py --reset`。
- **时区报错**：Windows 缺少 tzdata 时系统自动回退固定 UTC+8（已内置）。
- **已知限制**：
  - 模拟银行接口、模拟强验证（OTP）是否符合主办方验收口径为**待确认事项**。
  - 未接入真实银行/人脸/短信/U 盾；强验证为模拟实现。
  - GitHub 仓库地址尚未创建，列为待补事项。
