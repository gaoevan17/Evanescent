# DESIGN.md — 共识护航答辩 PPT 设计稿

## 画布
- 1280 × 720，16:9。安全区 padding 48。
- 母版三区：标题块 0–110px / 内容区 110–650px / 页脚 650–720px。

## 配色（≤4 种主色）
- 主色 primary：`#1a73e8`（蓝）
- 深色 dark：`#0f172a`
- 强调 red：`#d93025`（权限红/警示）
- 强调 yellow：`#b26a00`、green：`#1e8e3e`（用于绿/黄/红权限示意，作为语义色）
- 中性 bg：`#f0f4f8`、muted：`#64748b`

## 字体
- 标题：Microsoft YaHei，bold
- 正文：Microsoft YaHei，regular

## 布局节奏
- 封面 hero / 问题 / 定位 / 六场景 / 验收案例 / 权限 / 架构 / 安全 / 联动 / 测试 / 创新 / 边界致谢。
- 每页至少一个视觉锚点（大数字/色块/卡片），留白 ≤ 35%。
- 连续页版式避免重复。

## 语义色约定
- 绿 #1e8e3e、黄 #b26a00、红 #d93025 仅在权限分级/状态语义处使用。
